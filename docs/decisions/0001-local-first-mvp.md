# ADR-0001：首版采用纯本地实现

- Status: Accepted
- Date: 2026-09-09

## Context

项目最初考虑使用 OpenAI API 对抓取内容进行策略分析。但 ChatGPT 订阅不包含 API 用量，接入 API 还会引入独立计费、密钥管理、本地或云端服务、用户鉴权和隐私披露。当前首要目标是验证网页正文能否稳定抓取。

## Decision

首版只在 Chrome 扩展本地执行：读取用户主动授权的当前页面、清洗正文、转换 Markdown、预览、复制、下载和导出脱敏诊断样本。

当前不包含后端、用户系统、OpenAI API、远程存储或自动上传。未来 AI 能力必须通过独立 provider/后端边界接入，API Key 不得写入扩展源码。

## Consequences

- 安装和使用不产生服务器或模型费用。
- 页面内容默认不离开用户设备。
- 无需运行本地 Node.js 服务即可使用扩展。
- 暂时无法直接生成 AI 摘要或策略分析。
- 将来接入 AI 时需要新增独立决策，覆盖数据流、密钥、计费和隐私。

## Revisit when

正文抓取质量稳定，并且 AI 分析的用户价值、部署方式、成本承担和数据政策已经明确。
