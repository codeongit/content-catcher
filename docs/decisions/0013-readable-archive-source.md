# ADR-0013：收藏原文统一直接呈现 Markdown

- Status: Accepted
- Date: 2026-09-18
- Partially supersedes: [ADR-0010](0010-on-demand-obsidian-archive.md) 的收藏提示版本与原文呈现约定；材料检查、设置接口、权限、重复冲突及写入边界继续有效。

## Context

原有“原样保留抓取 Markdown”没有说明是否额外包裹代码围栏，外部模型有时直接保存正文，有时把整篇原文放入代码块，导致 Obsidian 中的阅读形式不一致。用户明确要求统一收藏原文格式。

## Decision

扩展 `0.8.2` 将收藏提示升级为 `archive-v2`。原文单独成节，直接作为可渲染的 Markdown 保存，不额外用代码围栏或整体缩进包裹整篇抓取稿。原文自身的元数据、标题、段落、列表、表格、图片引用、链接、代码块与空白保持原样；不能误删原文中的代码围栏或 Markdown 示例。

聊天中为方便复制而使用的外层围栏只是交付包装，不进入实际文件。保存后核对原文没有额外的整篇代码块包裹。该约定不要求改写标题层级、重排原文或移除元数据。

`buildArchivePrompt(options = {})`、设置键和 JSON 数据边界不变。`evidence-v4`、解析器、普通复制、下载及收藏冲突处理不变。扩展仍只复制指令，不读取对话或 Obsidian 文件，不新增模型调用、权限或自动格式修复器。

既有笔记不自动批量迁移。只有用户明确要求修正的文件才由有文件能力的执行者修改；保留原有阅读笔记，比较去除额外包装前后的原文内容，确保原文不变。

## Validation

专项离线测试检查原文直接呈现、保留内部代码、交付包装与文件内容的区别，并继续验证材料缺失、重复冲突、路径边界及失败降级。文本断言仅证明交接要求存在，不能保证外部模型输出遵守。

Chrome 实际复制和 Obsidian 阅读视图由人工维护者验证；未执行时标记待验证。真实文章不进入代码仓库或回归样本。

## Consequences

- 收藏原文的标题、表格、列表等可按 Markdown 正常呈现，保持与原始抓取稿相同的内容。
- 原文自带代码仍以代码块展示；这是原文的一部分，不属于需要去掉的额外包装。
- 外部模型仍可能未遵守提示，实际文件检查是保存结果的依据。
