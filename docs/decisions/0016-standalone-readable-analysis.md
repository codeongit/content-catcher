# ADR-0016：无需先读原文的分析讲解

- Status: Accepted
- Date: 2026-10-04
- Partially superseded by: [ADR-0021](0021-concise-article-analysis.md)（2026-11-04）：五部分默认结构与表达组织被精简；独立可读、原文例子与关键条件继续有效。
- Partially superseded by: [ADR-0017](0017-mainline-analysis-and-shared-limitations.md) 的提示版本与章节组织；独立可读与证据边界继续有效。
- Partially superseded by: [ADR-0020](0020-question-led-explanation.md) 的默认表达细节；独立可读与证据边界继续有效。
- Partially supersedes: [ADR-0015](0015-core-decision-prioritization.md) 的提示版本与默认表达组织；核心决策筛选与证据边界继续有效。

## Context

用户试用新版分析后指出，不看原文直接看分析仍难理解。输出偏重逐项评价，没有先讲清作者的方法，读者需要自行理解对象、证据槽等术语。用户明确批准调整默认讲解顺序。

## Decision

扩展 `0.8.5` 使用 `evidence-v7`。合并默认表达要求：默认读者没读过原文，先讲清作者面对的问题、做法及运作过程，再评价证据与价值。

定位与价值部分用合适的原文例子解释方法，没有例子时不编造；非方法类文章讲清讨论的问题和主要解释，不强套操作流程。必要术语在具体做法或含义之后引入，不用术语清单代替解释。核心主张先用具体行为、变化或通俗命题表达，再给依据和支持边界，不缩窄主张。

五部分默认结构保留，各项只展开关键边界，共同限制集中说明，避免证据评价打断讲解。完整主张、关键条件、证据类型、推导标记、用户偏好覆盖与抓取限制继续有效。设置、接口、索引、原样正文、权限及 `archive-v2` 不变。

## Verification

用有原文例子与无例子的合成材料检查独立可读、讲解顺序和不编造要求进入交接输入，并核对原文和索引不被改写。已有测试继续验证完整主张、独立验证、用户偏好与数据边界。离线检查不证明模型一定按顺序解释，也不证明读者理解程度。

按需人工观察：未读原文者能否说明作者解决什么问题、如何处理；无例子时是否编造，非方法类文章是否被强套步骤，通俗化是否缩窄主张。实际模型表现与 Chrome 复制流程待人工验证，真实文章不入库。

## Consequences

分析兼顾讲解和评价，可在不读取原文时理解主线。讲解仍受抓取证据边界限制，不引入外部背景来补齐方法。

## Revisit when

讲解占用过多篇幅、非方法文章被强套流程，或通俗化丢失重要条件时重新评估。
