# ADR-0022：围绕核心论证组织简短要点

- Status: Accepted
- Date: 2026-11-04
- Partially superseded by: [ADR-0023](0023-core-logic-and-takeaways.md)（2026-11-16）：提示版本、固定 2–3 个要点及借鉴内容的组织方式；保留核心论证、原文依据、关键条件和安全边界。
- Partially supersedes: [ADR-0021](0021-concise-article-analysis.md) 的提示版本与要点组织措辞；一句话主旨、2–3 个要点及证据和安全边界继续有效。

## Context

用户比较两版文章解析后，明确同意小幅调整内容组织：保留核心论证的重要联系，避免一个要点塞入多个主题，让依据、限制和启发自然融入解释。现有证据规则已覆盖引用定位、推断区分与验证条件，不因单次回答失误继续叠加核对规则，也不把某篇文章的结构变成通用模板。

## Decision

扩展 `0.8.11` 使用 `evidence-v13`。合并改写主提示中的组织和表达段落，仍先给一句话主旨与 2–3 个要点，每条以加粗短句直接说内容，再解释原因或做法及原文依据。

要点按作者的核心论证组织，保留问题、解释和结论之间的重要联系，不固定套用一种内容结构。每点围绕一个中心判断，只保留讲清它所需的内容，不为了覆盖全部章节而塞入多个主题。

使用日常语言并解释必要术语；有合适的原文例子时用它说明抽象机制。依据、必要限制和值得带走的认识或做法自然融入解释，不固定重复“原文依据”“值得带走”等标签，不强编操作步骤或读者原有习惯。

完整主张、关键条件、推断标记、主张与证据匹配、实验比较及独立验证等现有约束继续有效。核对规则和后续交接文本不变；原样抓取稿、证据索引、上下文、偏好、保存授权、独立收藏及扩展权限不变，不引入网络或模型调用。

## Verification

更新现有合成材料的交接测试，检查上述组织要求进入复制给模型的输入，并继续验证版本、证据规则、偏好覆盖、索引与原文保留及保存边界。运行 `npm ci`、全量离线测试、静态检查与 diff 检查。

文本断言只证明交接指令与数据正确，不证明外部模型输出已经改善。Chrome 复制流程和不同类型文章的实际表现待人工验证：要点应保留重要论证联系、各有中心、减少重复标签，同时保留影响判断的条件与证据限制。

## Consequences

这是内容组织的局部调整，不扩大证据审查要求，也不指定所有文章都遵循“问题—架构—迁移”等固定内容分工。现有表达偏好仍只覆盖对应维度，不能取消证据边界。

## Revisit when

多个不同类型的案例持续出现重要主张被挤掉、要点拥挤或固定模板取代原文论证时，再结合材料评估；单次表现不证明通用改善或需要新增默认规则。
