# ADR-0023：先讲清核心逻辑，再提炼借鉴价值

- Status: Accepted
- Date: 2026-11-16
- Partially supersedes: [ADR-0021](0021-concise-article-analysis.md)、[ADR-0022](0022-focused-article-points.md) 的提示版本、固定 2–3 个要点及借鉴内容仅融入要点的组织安排；完整主张、证据核对、偏好、后续交接和安全边界继续有效。

## Context

用户比较收藏笔记与聊天讲解后，明确要求整体调整分析提示，并认可先给总判断、再展开完整逻辑关系的介绍方式。现有默认把正文压成 2–3 个要点，并把借鉴内容融入其中，容易让多个重要环节挤在一起，或只列作者做过的事情，读者仍需自行还原关系和用途。

本次调整针对用户明确提出的分析目标，优先替换已有组织要求，不因单篇文章新增核对清单。具体文章的六步结构、领域术语或双闭环概括，不作为其他文章的默认模板。

## Decision

扩展 `0.8.12` 使用 `evidence-v14`。主提示重点回答“核心逻辑是什么，有什么可以借鉴”，保留主提示、核对规则与后续交接的分区。

先用一句话概括文章的核心判断，再按原文实际的因果、递进、对比或并列关系展开，说明关键观点或环节为什么提出、彼此有什么关系、作者最终得出什么结论。不只罗列章节或做法，也不把局部亮点当成全文主旨。

条目数量和篇幅以讲清主线为准，不再固定 2–3 点。有先后关系时可用编号串起逻辑链，复杂环节可分组说明，没有先后关系时不硬排成流程。每点用加粗短句直接说内容，再解释必要的原因、做法和原文依据。删除旁支与重复，保留关键联系，不为覆盖所有章节而堆细节。

可借鉴的认识或做法需说明适用情况、具体内容及原因，可在讲清核心逻辑后单独列出，也可融入相关解释。避免再次复述摘要，不凑数，不强编操作步骤或读者原有习惯。通俗表达、必要术语解释、原文例子、关键条件及共同限制只说一次的要求继续有效。

核对规则和后续交接文本保持不变。主张范围、条件与强度，推断标记，主张与证据匹配，实验比较与独立验证等约束继续有效。`archive-v2`、原样抓取稿、索引、上下文、设置、保存授权、接口及扩展权限不变，不引入网络或模型调用，不修改已有收藏笔记。

## Verification

更新已有合成材料的离线交接测试，检查核心判断先行、实际逻辑关系、灵活条目数量、非流程文章处理，以及可借鉴内容的适用情况、内容和原因进入提示。继续验证证据规则、版本、偏好覆盖、索引、原样正文和保存边界。运行 `npm ci`、全量离线测试、静态检查与 diff 检查。

文本断言只验证交接指令与数据，不证明外部模型已经讲得更清楚。不同类型文章的实际表现和 Chrome 复制流程待人工验证：读者应能从首句和加粗部分复述主旨，读完解释后说清关键关系与借鉴价值；复杂文章不丢重要环节，并列观点不被硬排为流程，借鉴内容不重复摘要，证据边界仍保留。不引入付费模型重复测试，也不把单次观察当作普遍改善的证明。

## Consequences

输出可以比旧版更长，以容纳必要关系和解释；仍需删去旁支、重复和无关细节。借鉴内容的呈现方式更灵活，不要求固定章节、条目数量或所有文章都有操作清单。现有偏好继续按表达维度覆盖，不能取消事实边界。

## Revisit when

多个不同类型的案例持续出现目录式罗列、篇幅无谓膨胀、借鉴内容重复摘要，或复杂主张仍被压缩失真时，再结合材料评估；单次表现不自动形成新的默认规则。
