# ADR-0020：按读者问题讲清主张与证据

- Status: Accepted
- Date: 2026-10-20
- Partially superseded by: [ADR-0021](0021-concise-article-analysis.md)（2026-11-04）：提示版本与默认五部分改为一句话主旨与 2–3 个要点；独立可读、完整主张与证据边界继续有效。
- Partially supersedes: [ADR-0019](0019-explicit-insight-changes.md) 的提示版本，以及 [ADR-0016](0016-standalone-readable-analysis.md)、[ADR-0017](0017-mainline-analysis-and-shared-limitations.md) 的默认表达与核心主张组织细节；完整主张、主线筛选和证据边界继续有效。

## Context

用户指出分析中的一项虽列出分类和证据评价，却未把各部分的关系解释清楚，并同意优化提示词。已有规则要求先解释方法，但按主题合并内容和密集覆盖信息的要求仍可能诱发概念罗列。这是经用户确认的表达调整，不将单次模型失误认定为普遍缺陷，也不把原文章节的具体分类写成通用规则。

## Decision

扩展 `0.8.9` 使用 `evidence-v11`，直接改写已有默认表达与第 2 部分，不增加独立规则层。

每项核心主张聚焦一个读者需要理解的问题，标题直接说明作者主张。只合并共同回答该问题的相关主张，不因主题相关就插入打断解释的概念；合并仍保留各自范围、条件、强度和证据。

方法解释有合适的原文例子时，优先用同一个例子串起做法、环节关系与作用，再引入必要术语。没有例子时不编造，非方法类文章不强套步骤。证据评价直接说明具体材料能确认什么、还不能确认什么，不用抽象标签替代解释；内容要求不强制成为固定输出栏目。精简时先删旁支和重复评价，保留理解所需的解释与关键条件。

五部分默认结构、实用见解、偏好覆盖、原文、索引、设置、接口、权限及 `archive-v2` 保留。此次不修改已收藏笔记。

## Verification

扩展已有独立可读性测试，用包含不同检查环节及旁支概念的合成材料，以及没有案例与操作流程的观点材料，验证新版要求进入交接输入，完整主张、证据边界、索引和原文保持不变。运行全量离线测试与静态检查。

文本断言仅确认交接内容，不证明外部模型可读性已经改善。实际模型表现和 Chrome 复制流程待人工验证；按需观察读者能否复述做法及环节关系，是否仍需自行翻译抽象评价，以及是否因简化丢失关键条件。真实文章不入库，不调用外部模型 API。

## Consequences

解释顺序围绕读者的问题，避免分类清单和固定栏目占据讲解主体。规则不要求每项必须有例子，也不允许以便于举例为由选择次要主张。

## Revisit when

同一例子被过度延伸、复杂主张被缩窄为单一问题，或解释过长导致关键证据条件被挤出时重新评估。
