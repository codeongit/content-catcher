# ADR-0005：解析问题采用回归优先维护

- Status: Accepted
- Date: 2026-09-09

## Context

网页解析依赖启发式规则。修复一个网站可能改变候选评分或清洗范围，从而破坏之前已经正常的网站。最初针对同一篇微信文章经历多轮修正，也说明只靠人工复测无法长期扩展。

## Decision

每个可复现的解析问题必须遵循：

```text
问题描述 → 脱敏诊断 → 最小 fixture → 失败测试
→ 最小修复 → 全量回归 → 版本记录 → CI 通过
```

使用 jsdom 执行与扩展相同的 `extractor.js`。GitHub Actions 在每次 push 和 pull request 时运行解析测试和静态检查。

## Consequences

- 每修复一个新页面，项目都会增加永久的防回归样本。
- 维护者需要先写失败断言，不能只在真实网页上目测。
- 实时网站不会进入 CI，测试必须确定、离线、无网络依赖。
- 推送后的工作只有在 GitHub Actions 成功后才算完成。
