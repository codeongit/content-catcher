# ADR-0018：围绕文章主旨提炼实用见解

- Status: Accepted
- Date: 2026-10-04
- Partially superseded by: [ADR-0019](0019-explicit-insight-changes.md) 的提示版本与见解选取表达；主旨导向和证据边界继续有效。
- Partially supersedes: [ADR-0017](0017-mainline-analysis-and-shared-limitations.md) 的提示版本与实用见解要求；主线组织和证据边界继续有效。

## Context

用户指出实用见解仍难理解，并确认重点不是把局部技巧写成行动，而是围绕文章最想表达的内容提炼认识或做法的改变。用户明确批准替换相关指引。

## Decision

扩展 `0.8.7` 使用 `evidence-v9`。第 3 部分先确定文章最想改变读者的什么认识或做法，再提炼值得采用的见解。行动和原文例子解释这项改变，不取代它；不能因为局部例子容易具体化而提升为主要建议。

用通俗语言说明适用情况、值得改变什么及原因。理解框架类文章可以说明如何改变判断，不强编操作清单。简短交代依据与关键边界，推导明确标记，没有足够依据则省略，不凑满条目、不固定建议模板，不编造例子。

替换原先要求每条必须给具体行动的措辞；筛选规则统一指向第 3 部分，减少重复定义。完整主张、证据约束、章节组织、偏好覆盖、原样正文、索引、本地设置、接口、权限及 `archive-v2` 不变。

## Verification

离线测试用同时含主旨与局部例子的合成材料，以及只提供理解框架的材料，检查新要求、依据边界和推导标记进入交接输入，索引与原文保持不变。文本断言不证明模型能够正确提炼主旨。

实际模型输出与 Chrome 复制流程待人工验证。按需观察是否围绕主旨、是否强编行动清单、是否丢失依据与适用边界；真实文章不入库。

## Consequences

实用价值包括改变判断与改变行动，不只包含操作步骤。主旨不明确或依据不足时不猜测用途，也不强行填满见解。

## Revisit when

见解只复述主旨而未解释价值，或过于抽象而无法理解适用情况与改变时重新评估。
