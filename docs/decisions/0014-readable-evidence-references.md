# ADR-0014：可读的分析证据定位

- Status: Accepted
- Date: 2026-10-03
- Partially superseded by: [ADR-0015](0015-core-decision-prioritization.md) 的提示版本；引用表达与核对边界继续有效。
- Partially supersedes: [ADR-0012](0012-decision-oriented-plain-language-analysis.md) 的提示版本和回答引用表达；证据评价与其他边界继续有效。

## Context

现有契约要求回答展示块编号，读者需要反复对照索引才能理解引用。用户明确批准将核对用的定位信息与面向读者的引用表达分开。

## Decision

扩展 `0.8.3` 使用 `evidence-v5`。回答默认用原文章节名与必要短引文定位依据，不显示块编号或行号。无标题、标题重复或定位不清时，使用有辨识度的短引文，不编造章节名。用户要求精确定位时附上编号或行号。

块编号和行号仍用于阅读、核对对应原文，索引不构成独立证据。同步替换评价规则与核心主张章节中强制展示编号的措辞，保留完整主张、证据支持范围和显式推导标记。

索引格式、抓取上下文、原样正文、偏好设置、函数接口、权限与按需反馈边界不变。收藏契约继续为 `archive-v2`，不增加模型调用或配置迁移。

## Verification

离线检查覆盖引用指令与旧强制展示措辞的移除，并用有标题、无标题、重复标题的合成材料检查索引及原样正文保留。文本断言不证明外部模型已经遵循规则。

三类材料的外部模型输出观察与 Chrome 复制流程均待人工验证；不保存真实文章或把本次聊天的修改结果当作新版提示效果证明。

## Consequences

读者可以直接理解引用位置，同时仍可按需获得精确定位。短引文须足以辨识对应原文，不能用可读性替代证据核对。

## Revisit when

用户需要默认展示精确编号，或可读引用持续无法区分原文位置时重新评估。
