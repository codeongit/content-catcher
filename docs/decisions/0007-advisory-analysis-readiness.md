# ADR-0007：使用非阻断的模型分析提示

- Status: Accepted
- Date: 2026-09-09

## Context

Content Catcher 的主要下游用途是把抓取结果交给模型总结和分析。严格判断网页是否被完整还原需要大量站点规则，并且容易把合法短文、无图文章或特殊排版误判为错误。用户更关心会不会因为正文不完整或范围不可信而影响模型结论。

## Decision

解析成功后增加独立的分析适用性判断层，只使用三个通用信号：清理后正文少于 300 字、正文选择回退到整个 `body`、删除文字超过 1000 字且超过原正文的 50%。

结果只有 `ready` 和 `review`，不计算数值置信度。提示最多两个，只提供事实性建议，不修改正文，也不阻止复制或下载。图片数量、作者缺失、标题格式、站点关键词和轻微 Markdown 差异不参与判断。

用户主动点击“复制给模型”时，扩展在原始 Markdown 前增加简短通用指令和已经触发的提示。普通复制和 Markdown 下载保持纯净。该功能只写入本地剪贴板，不调用 AI API，不改变 ADR-0001 的本地优先边界。

## Consequences

- 规则少且与站点无关，维护和回归成本较低。
- 合法短文可能收到建议确认提示，但不会被阻断。
- 提示覆盖高影响问题，不承诺发现所有格式或内容差异。
- 新增规则必须证明其对模型分析有明显影响，并同时验证误报边界。

## Revisit when

积累了足够多的真实误报或漏报样本，或者扩展开始直接调用模型服务并能够获得下游分析反馈。
