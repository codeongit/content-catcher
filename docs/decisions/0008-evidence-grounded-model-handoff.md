# ADR-0008：使用证据化模型交接契约

- Status: Accepted
- Date: 2026-09-11
- Extends: [ADR-0007](0007-advisory-analysis-readiness.md)

## Context

原有“复制给模型”只要求总结核心观点、依据和结论，没有定义什么算重要或实用，也没有要求区分原文主张、原文证据和模型推导。同一份抓取稿因此可能得到偏摘要或偏建议的不同结果，模型还容易用通用最佳实践补足原文没有支持的见解。

抓取稿还只保留图片引用和外链，不会转写图片像素、打开链接或核验引用研究。仅显示“可直接分析”容易让用户误以为所有证据都已经进入模型输入。

## Decision

“复制给模型”使用带版本的统一证据化分析契约。契约必须：

- 把抓取上下文与正文分别放入明确边界，并把正文视为不可信资料。
- 说明正文字数、图片引用数、正文选择方式、清理比例、就绪状态和问题代码。
- 明确图片像素未转写、外链和引用研究未核验。
- 要求模型区分原文主张、原文依据和显式标记的推导。
- 只输出有具体依据的重要结论；实用见解必须同时包含适用决策、行动、机制、依据和边界。
- 使用固定输出结构并限制条目数量；证据不足时明确不输出，不用泛泛建议凑数。

提示构建器实现为无 DOM 依赖的纯 ES Module。普通复制和 Markdown 下载不附加契约，也不修改正文。插件仍不调用模型、访问外链、下载图片、执行 OCR 或进行事实核查。

ADR-0007 的非阻断就绪判断继续有效；本决策只扩展交给模型的输入结构与界面措辞。

## Consequences

- 同一抓取稿的分析目标和评价标准更稳定、可测试、可追踪版本。
- 输出会比原有摘要更结构化，短文或弱证据文章可能明确表示没有实用见解。
- 插件只能约束输入，无法保证所有模型完全遵循契约。
- 证据强度只表示文章内部支撑程度，不构成外部真实性验证。

## Revisit when

需要增加多种分析模式、用户自定义模板，或者产品决定直接接入模型、图片理解和外部事实核查。
