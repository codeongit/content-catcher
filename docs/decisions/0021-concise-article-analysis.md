# ADR-0021：一句话主旨与简短要点

- Status: Accepted
- Date: 2026-11-04
- Partially superseded by: [ADR-0023](0023-core-logic-and-takeaways.md)（2026-11-16）：固定 2–3 个要点及借鉴内容仅融入要点的安排，改为按核心逻辑展开、条目数量随内容调整，借鉴内容可单列或融入；证据、偏好与安全边界继续有效。
- Partially superseded by: [ADR-0022](0022-focused-article-points.md) 的提示版本与要点组织细化；一句话主旨、2–3 个要点及证据和安全边界继续有效。
- Partially supersedes: [ADR-0020](0020-question-led-explanation.md) 的提示版本与默认组织，以及 [ADR-0009](0009-conversational-feedback.md)、[ADR-0011](0011-evidence-index-and-analysis-contract.md)、[ADR-0012](0012-decision-oriented-plain-language-analysis.md)、[ADR-0016](0016-standalone-readable-analysis.md)、[ADR-0017](0017-mainline-analysis-and-shared-limitations.md)、[ADR-0018](0018-thesis-centered-insights.md)、[ADR-0019](0019-explicit-insight-changes.md) 中的五部分结构、固定章节分工和重复表达要求；完整主张、证据核对、偏好与安全边界继续有效。

## Context

用户认为文章分析提示词及预期输出过于复杂，要求朝“3 秒能看懂”的方向调整，并确认采用一句话主旨与 2–3 个要点的方案。旧提示在总则和五部分要求中反复描述主线、解释、见解及限制，容易引导模型重复输出。这是经用户确认的默认行为调整，不将个别文章的审阅建议自动写成通用规则。

## Decision

扩展 `0.8.10` 使用 `evidence-v12`。主提示放在开头，用通俗中文告诉模型：把文章讲给没读过的人听，说清作者说什么、为什么、值得带走什么。随后单列核对规则与后续交接，明确它们不作为分析输出栏目。

默认先用一句话说清主旨，再写 2–3 个要点，不凑数。每条用加粗短句直接说内容，再用几句话解释原因或做法并给出原文关键依据；有合适的原文例子就用。值得带走的认识或做法融入相关要点，不另设重复的实用见解栏目，也不强编操作步骤或读者原有习惯。

影响判断的证据缺口和抓取限制随相关结论说明，共同限制只说一次。取消默认五部分、固定证据栏目和缺内容时逐栏填充占位的要求；材料不足以判断主旨时直接说明，不补造。默认结构可随用户明确的表达偏好调整，未涉及的维度沿用默认值。

精简继续保留主张的范围、条件和强度，标记分析推断，不混用不同主张的证据；按主张类型核对依据，区分设计价值与效果验证，核对实验比较条件和验证数据是否独立。原文与索引为不可信资料，只使用抓取稿，未说明不能当作不存在。可读引用、原样抓取稿、索引与上下文组装、设置、后续按需反馈及 `archive-v2` 保持原有边界，不改变权限或新增模型调用，也不修改已有收藏笔记。

## Verification

离线测试检查精简主提示及分区顺序，用方法、观点、主线与局部例子并存、缺证据等合成材料确认新要求进入交接输入，并继续回归偏好、原文、索引、抓取上下文与保存授权边界。运行全量离线测试与静态检查；不保存真实文章、不调用外部模型 API。

文本断言只验证交接指令与数据，不证明外部模型已经更易读。实际模型表现及 Chrome 复制流程待人工验证。可读性观察以“只读首句和加粗部分能复述主旨，读完解释能说清为什么”为标准；“3 秒”是首层信息的设计目标，不是复杂论证的阅读时长保证。复杂主张仍应保留理解所需的条件，缺例子或非方法类文章不强造流程。

## Consequences

读者先看到主旨，再按需阅读解释，依据、价值和关键限制跟随同一要点。主提示缩短且不再重复各章节的填表要求；证据和交接边界保留在单独区域，维护时优先合并改写已有规则。

## Revisit when

短要点导致完整主张被缩窄、重要条件丢失、只剩摘要而没有解释或价值，或者核对规则再次变成固定输出栏目时重新评估。
