# ADR-0002：通用解析器与站点适配器组合

- Status: Accepted
- Date: 2026-09-09

## Context

只为微信公众号编写选择器无法支持新闻、博客等新网站；只使用通用启发式又会在微信等非语义化页面中选中更大的外层容器，混入作者区、页面提示和推荐内容。

## Decision

解析流程采用两层结构：

1. `SITE_ADAPTERS` 只处理稳定且明确的站点差异，包括匹配条件、正文根节点、站点元数据和额外清洗。
2. 通用解析层负责语义节点选择、候选评分、通用 DOM 清洗、链接和图片规范化以及 Markdown 转换。

匹配到适配器时仍复用通用转换流程，不复制整套解析器。当前微信适配器优先使用 `#js_content`，并拆分文章作者与公众号账号。

## Consequences

- 新网站通常无需新增适配器即可工作。
- 特殊网站可以精确修复，而不污染通用算法。
- 必须防止 hostname 判断散落到通用函数中。
- 每个适配器都需要独立 fixture 和回归测试。

## Rejected alternatives

- 站点白名单解析：覆盖面差，维护成本随网站数量线性增加。
- 纯通用评分：难以可靠处理微信等结构特殊的页面。
