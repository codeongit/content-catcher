# ADR-0017：按文章主线组织与集中共同证据缺口

- Status: Accepted
- Date: 2026-10-04
- Partially superseded by: [ADR-0018](0018-thesis-centered-insights.md) 的提示版本与实用见解要求；主线组织和证据边界继续有效。
- Partially supersedes: [ADR-0016](0016-standalone-readable-analysis.md) 的提示版本与章节组织；独立可读与证据边界继续有效。

## Context

用户试用后确认开头讲解更清楚，但逐项评价仍重复证据不足，实用见解排序需更贴近核心决策。用户批准合并组织要求，减少重复推导，而非继续追加旁支规则。

## Decision

扩展 `0.8.6` 使用 `evidence-v8`。核心主张围绕主线组织，最多五项而非凑满五项。紧密相关的主张可合并，但保留各自范围、条件、强度和证据，不得以较弱命题替代强主张或混用依据。

每项先讲清作者的意思与论证，再简要评价依据及关键边界。重复推导合并或删除，必要推导仍显式标记。实用见解按对核心决策的影响排序，优先改变采用方式、行动或职责分配的建议；局部技巧可作为例子，仍不固定套用建议模板。

第 2 部分保留影响具体判断的特殊缺口；第 4 部分集中共同证据缺口及关键未证结论；第 5 部分只依据抓取上下文说明抓取和访问限制。精简不能隐藏会改变判断的条件与不确定性。

保留五部分默认结构、独立可读、完整主张、证据类型、独立验证、偏好覆盖、原样正文、索引和本地设置。接口、权限及 `archive-v2` 不变。

## Verification

离线检查新版组织指令进入交接输入，合并主张的条件与证据保护、推导标记和不确定性同时保留；现有索引、原文与偏好数据回归继续运行。文本断言不证明模型输出更短或更易理解。

按需人工观察合成材料：同一方法的设计主张与普遍效果主张并存、共享证据缺口，并含一个局部技巧。检查是否按主线组织而不混用证据、特殊缺口是否仍明确、是否减少共同缺口和推导重复。实际模型与 Chrome 复制流程待人工验证，真实文章不入库。

## Consequences

讲解与评价的篇幅分配更贴近主线，共同限制集中而不被隐藏。条目上限仍在，不要求固定数量，单次输出改善不能证明普遍有效。

## Revisit when

合并造成主张强度混淆、共同缺口集中后影响具体判断的边界不清，或篇幅仍因重复评价膨胀时重新评估。
