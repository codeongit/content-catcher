# ADR-0004：诊断样本脱敏，测试只使用合成 fixture

- Status: Accepted
- Date: 2026-09-09

## Context

真实网站解析问题需要观察 DOM 结构，但保存和提交完整网页可能包含版权文章、个人信息、登录后数据、跟踪参数和真实资源地址。仅根据 Markdown 输出又无法稳定复现节点嵌套和选择器问题。

## Decision

扩展提供用户主动触发的“导出脱敏诊断样本”：

- 保留必要的 DOM 层级、标签、稳定 id/class、语义属性和懒加载属性。
- 将普通正文替换为长度占位符。
- 将真实链接和图片地址替换为 `example.invalid`。
- 只保留复现清洗规则所必需的已知噪声标记。
- 只下载到本地，不自动上传。

仓库中的 `tests/fixtures/` 只保存由诊断结构进一步压缩得到的最小合成 HTML，不保存完整真实文章。

## Consequences

- 可以在不提交真实文章内容的情况下复现大部分结构问题。
- 脱敏样本不保证完全复现依赖 CSS、脚本或运行时状态的问题。
- 任何新增诊断字段都必须重新做隐私评估和脱敏测试。
