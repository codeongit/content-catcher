# ADR-0006：正文选择语义优先，清洗保持保守

- Status: Accepted
- Date: 2026-09-09

## Context

通用页面可能同时包含 `main`、`article`、侧边栏和推荐内容。单纯选择文本最多的容器容易把页面框架当作正文；过于激进的关键词删除又可能删掉文章中的合法短段落。

## Decision

正文根节点按以下优先级确定：

1. 已匹配站点适配器的明确正文根节点。
2. 长度足够的语义 `article` 或 `itemprop=articleBody`。
3. 对候选节点按文本长度、段落、标题、图片、链接密度和正负向标识评分。

通用清洗只删除高置信度页面组件。语义型尾部截断必须同时受站点、内容位置、DOM 结构和回归测试约束。

## Consequences

- 优先减少“正文不完整”和“误删正常内容”的高损失错误。
- 某些网站可能保留少量噪声，需要通过诊断和适配器逐步收敛。
- 不允许为了修复单页，在通用层增加无位置约束的宽泛文本删除规则。
