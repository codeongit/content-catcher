# ADR-0019：实用见解讲清最值得带走的改变

- Status: Accepted
- Date: 2026-10-04
- Partially superseded by: [ADR-0021](0021-concise-article-analysis.md)（2026-11-04）：实用见解的固定栏目与重复表达要求被合并；重要改变、不虚构读者习惯与证据边界继续有效。
- Partially superseded by: [ADR-0020](0020-question-led-explanation.md) 的提示版本；实用见解选取与证据边界继续有效。
- Partially supersedes: [ADR-0018](0018-thesis-centered-insights.md) 的提示版本与见解选取表达；主旨导向和证据边界继续有效。

## Context

用户确认需要修改内置提示词，持续改善实用见解的选取和可理解性，而不只修订单份分析。现有见解仍可能偏向次要主张，或使用抽象概括而未讲清改变。

## Decision

扩展 `0.8.8` 使用 `evidence-v10`。在已有第 3 部分内明确：优先选择文章主线中最值得读者带走的认识或做法改变，不优先选容易举例的局部技巧或次要主张。

依据原文讲清原来怎样想或做、建议改变什么、为什么值得改变。原文未交代原有做法时，不虚构读者习惯，只解释适用情况和改变。标题与正文直接说清改变，不只用抽象概括作结；不禁止必要术语，也不把当前文章的见解类别固定成模板。

行动与原文例子解释核心改变，理解框架类文章不强编操作清单。依据、适用边界、推导标记、偏好覆盖、章节组织、原文、索引、本地设置、接口、权限及 `archive-v2` 保留。

## Verification

离线测试用主线与次要主张并存、以及未描述原有做法的合成材料，验证选取优先级、直白解释与不虚构要求进入交接，原文和索引保持不变。文本断言不验证外部模型实际选取质量。

实际模型表现和 Chrome 复制流程待人工验证。按需观察主线是否优先、改变及原因是否能读懂、是否虚构读者习惯；真实文章不入库。

## Consequences

默认要求在每次交接中传给模型，单份修订不被当成未来效果保证。认识改变和行动改变均可有实用价值，仍需依据文章选取。

## Revisit when

对比表达导致虚构原有习惯，或见解退化为泛泛口号、忽略文章关键条件时重新评估。
