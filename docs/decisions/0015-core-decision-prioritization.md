# ADR-0015：核心决策优先的内容筛选

- Status: Accepted
- Date: 2026-10-04
- Partially superseded by: [ADR-0016](0016-standalone-readable-analysis.md) 的提示版本与默认表达组织；核心决策筛选与证据边界继续有效。
- Partially supersedes: [ADR-0014](0014-readable-evidence-references.md) 的提示版本；补充 ADR-0012 的重点筛选与表达要求，原有证据边界继续有效。

## Context

用户确认直接调整内置提示词：先选出文章最重要的决策与实用见解，避免容易具体化的局部技巧占据重点，减少重复证据限制与旁支风险推导。此项为明确授权的默认要求修改，不自动把单次纠正转成产品规则。

## Decision

扩展 `0.8.4` 使用 `evidence-v6`。先围绕文章核心决策筛选重要内容，再展开证据评价。实用见解优先选择能改变采用方式或行动的建议；局部例子可解释核心建议，不因容易具体化而优先单列。继续不固定所有文章采用同一组决策；局部技巧本身为文章主旨时仍可成为核心见解。

分别说明方法的设计价值与效果验证程度，不因效果尚未证明而忽略有依据的设计价值。主张先行，依据紧跟；各项只展开关键边界，共同限制集中说明，避免反复强调证据不足。新增推导只保留会改变理解或决策的内容。

完整主张、证据类型、独立验证与推导标记要求不变；不能以简洁为由省略关键条件。用户偏好按维度覆盖默认，空偏好、本地存储、接口、索引、抓取原文、权限及 `archive-v2` 不变。

## Verification

离线测试检查新版契约是否传入核心决策筛选、设计与效果分开及精简推导要求，同时保留证据边界、用户偏好数据、索引与原样正文。文本测试不证明外部模型输出质量。

按需人工观察复杂文章中整体选择与局部例子的优先级，以及局部技巧为主旨时能否仍正确选取；实际模型表现和 Chrome 重新加载、复制流程待人工验证。真实文章不入库。

## Consequences

默认分析更强调内容排序和决策价值，不增加一套固定建议模板，也不削弱证据要求。模型能否遵循仍依赖实际输出观察，不能用本次聊天修订证明普遍改善。

## Revisit when

重点筛选持续遗漏关键局部技巧，或精简表达导致关键证据边界缺失时重新评估。
